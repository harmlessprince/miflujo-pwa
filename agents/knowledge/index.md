# agents/knowledge — Index

All deep-dive knowledge files for the MiFlujo codebase. Each file supplements
`CLAUDE.md` with rules too detailed to fit in the main reference.

| File | Covers |
|---|---|
| `design-system-rule.md` | Color tokens, typography scale, interactive dimensions, error vs primary usage, financial data formatting |
| `logo-usage-rule.md` | Which MiFlujo logo asset to use per page/layout; forbids bare text or icon-only logo replacements |
| `form-components-rule.md` | When to use existing form primitives vs raw HTML elements; full component mapping |
| `component-rules.md` | Folder structure, `<script setup>` shape, when to create vs extend components, DataTable usage, icon and slot conventions |
| `store-patterns.md` | Pinia Setup API patterns, per-action loading refs, toastStore usage, pagination with `getPaginatedData()`, store composition |
| `page-patterns.md` | Required page boilerplate, layout and middleware selection, sidebar registration, data fetching, dynamic routes |
